❌ Erreurs courantes et solutions

redirect_uri_mismatch

L'URL de callback ne correspond pas à celle configurée dans Google Cloud Console.

Solution: Ajoute exactement l'URL affichée ci-dessus dans la console Google.

disallowed_redirect_uri

L'hôte n'est pas dans ALLOWED_HOSTS.

Solution: Ajoute l'hôte dans ALLOWED_HOSTS dans settings.py.

📝 Instructions étape par étape

  1. Va sur Google Cloud Console
  2. Sélectionne ton projet
  3. Clique sur ton "OAuth 2.0 Client ID"
  4. Dans "Authorized redirect URIs", ajoute les URLs ci-dessus
  5. Clique sur "Save"
  6. Attends 5-10 minutes
  7. Redémarre le serveur Django
  8. Teste la connexion
